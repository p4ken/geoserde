# geoserde-fgb

[![crates.io](https://img.shields.io/crates/v/geoserde-fgb.svg)](https://crates.io/crates/geoserde-fgb)
[![docs.rs](https://img.shields.io/badge/_-docs.rs-slategray?logo=docsdotrs)](https://docs.rs/geoserde-fgb/)

geoserde-fgb reads and writes [FlatGeobuf](https://flatgeobuf.org/) features as your own Rust data structures, built on [geoserde](https://crates.io/crates/geoserde).

See [API documentation](https://docs.rs/geoserde-fgb).
